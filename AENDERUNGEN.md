# Änderungen / Changelog

## v1.0.0

**Deutsch**
- Erste öffentliche Version der Bildwerkstatt: Bilder für beliebige Projekte, lokal auf NVIDIA-Grafikkarten, kostenlos, ohne API.
- Mehrere Projekte in einem Fenster, Upload nach jedem Bild, Statusbericht und Neumal-Aufträge für Claude.
- Acht Bildmodelle (FLUX.2 klein, Z-Image, ERNIE-Image, LongCat-Image, Qwen-Image) mit Vorschlag passend zur Grafikkarte und Probebildern.
- Fenster auf Deutsch und Englisch, live umschaltbar. Installation auf jeder Festplatte, Modell-Ordner frei wählbar.
- Argus, der Wächter: Neustart bei Absturz, Autostart, Handy-Meldungen (ntfy) und Fernbefehle.

**English**
- First public release of the Image Workshop: images for any project, locally on NVIDIA graphics cards, free, no API.
- Several projects in one window, upload after every image, status report and re-render jobs for Claude.
- Eight image models (FLUX.2 klein, Z-Image, ERNIE-Image, LongCat-Image, Qwen-Image) with a recommendation for your graphics card and test images.
- Window in German and English, switchable live. Install on any drive, model folder freely selectable.
- Argus, the guardian: restart after crashes, autostart, phone messages (ntfy) and remote commands.
